# JK LAND Development & Design Rules

## UI/UX Design Directives (Web Wizard Mode)
- **High-End Polish**: All web components must meet Linear / Vercel / Apple design standards.
- **Color Discipline**: Avoid garish colors or flat borders. Use deep dark surfaces (`slate-950`, `zinc-950`), micro-borders (`border-white/10`), ambient blur glows, and precise accent highlights.
- **Bento Grid Architecture**: Arrange dashboards and portals in balanced, asymmetric Bento layouts.
- **Fluid Micro-interactions**: Include subtle hover states, active spring effects, smooth transitions, and tactile feedback.
- **Responsive Perfection**: Ensure flawless rendering on both desktop widescreen and mobile smartphones.
